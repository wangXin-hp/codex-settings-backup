## The Rule

**Invoke relevant or requested skills BEFORE any response or action** — including clarifying questions, exploring the codebase, or checking files. If it turns out wrong for the situation, you don't have to use it.

Then announce "Using [skill] to [purpose]" and follow the skill exactly.

## Skill Priority

When multiple skills apply, process skills come first; implementation skills carry out the work afterward.

## User Instructions

User instructions and repository instructions take precedence over skills.
